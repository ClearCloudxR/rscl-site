# RSC Website (`rscl-site`)

Xiamen No.1 Middle School Redstone Club (RSC) website.

## Theme

Claude-style visual language:

- **Fonts** — Anthropic Serif / Sans / Mono, self-hosted in `fonts/`
- **Palette** — warm black `#181715`, clay accent `#cc785c`
- **Theme** — light/dark toggle, dark by default

## Deploy

Connected to Cloudflare Pages (`rscl`), auto-deploys on push to `main`.

- https://rscl.factorization.top
- https://rscl.pages.dev
